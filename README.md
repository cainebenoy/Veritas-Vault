# Veritas Vault

This is a Next.js starter project for the SFLC.in Hackathon 2025.

**Veritas Vault** is a tool to permanently archive web pages on the decentralized web, creating a resilient and censorship-resistant record of online content.

## Getting Started

To get started, take a look at `src/app/page.tsx`.

To run the development server:

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.
